Interactive three-dimensional BT1 PCA

PC1-PC3 view of the same canonical 14-endpoint PCA used for the manuscript's two-dimensional PC1-PC2 biplot.

Interpretive scope

This visualization is descriptive. It was not used to test ethanol or measurement-context effects, and apparent group separation is not inferential evidence. The displayed components explain 50.8% of total variance after rounding.
